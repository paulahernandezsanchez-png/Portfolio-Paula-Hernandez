# portfoliooooo

Portfolio personal con estética de app de viajes (estilo Airbnb / Booking), construido en HTML, CSS y JavaScript puro — sin frameworks, listo para GitHub Pages.

El contenido actual (proyectos, itinerario, textos) es de ejemplo/placeholder y se sustituirá más adelante por contenido real.

## Estructura

```
index.html            página principal
assets/css/style.css  estilos (paleta, layout, responsive, animaciones)
assets/js/script.js   splash loader, scroll reveal, navbar activa, formularios demo
```

## Ver en local

```
python3 -m http.server 8000
```

y abre `http://localhost:8000`.

## Desplegar en GitHub Pages

Settings → Pages → Deploy from branch → selecciona la rama y la carpeta raíz (`/`).
